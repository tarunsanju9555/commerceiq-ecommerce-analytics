# CommerceIQ | E-Commerce Sales Analytics
\
## Dashboard Preview

![CommerceIQ Power BI Dashboard](powerbi_dashboard.png)

An end-to-end data analytics project exploring the Olist Brazilian E-Commerce dataset using **Python, SQL Server, and Power BI**.

### Tools
- **Python:** Pandas, data cleaning and validation
- **SQL Server:** Data storage, analysis and business queries
- **Power BI:** Interactive sales dashboard and visualizations

### Key Insights
- Analysed 96,478 delivered orders.
- Identified Health & Beauty as the leading product category by item sales.
- Found São Paulo to be the leading customer state by item sales.
- Explored monthly sales trends and customer review scores.

### Project Structure
- `src/` — Python inspection, validation and loading scripts
- `sql/` — SQL analysis queries
- `data/processed/` — Cleaned datasets and quality reports
- `powerbi/` — Power BI report and summary datasets

### Dataset
[Olist Brazilian E-Commerce Public Dataset](https://www.kaggle.com/olistbr/brazilian-ecommerce)

**Note:** This project was developed for learning and portfolio purposes. Sales figures depend on the filters and definitions used in each query.
